- 第 2 个问题（已追加到三文档）：解释 D 盘与 C 盘同时出现 python.exe 的原因。结论：D 盘是 python.org 官方解释器（3.13.7），C 盘是 Microsoft Store 的"应用执行别名"重定向器；`py -0p` 只列出 D 盘，说明真正注册的解释器只有 D 盘那个。
- 第 3 个问题（已追加到三文档）：解释器与环境的关系 + 无解释器能否写代码。结论：解释器=`python.exe`（引擎），环境=解释器+标准库+第三方包(可选)+配置；无解释器可写 `.py` 文本但不能运行/测试（IDE 静态检查不算执行）。
- 第 4 个问题（已追加到三文档）：是否将 `D:\py\Scripts` 加入 PATH。结论：建议加入以便直接调用 pip 及 pip 安装的工具；本机 `where pip` 已指向 `D:\py\Scripts\pip.exe`，说明已配置好；若 `C:\Python38` 不用可清理。
- 第 5 个问题（已追加到三文档）：为何环境变量里看不到 `py`。结论：`py.exe` 装在 `C:\Windows`，而 `C:\Windows` 是默认 PATH 目录，所以无需手动加条目；`py` 是全局启动器，`python` 才是具体安装的解释器（需各自 PATH 条目）。本机 `D:\py`/`D:\py\Scripts` 已在 PATH。

- 第 6 个问题（已追加到三文档）：Python 退出指令是否只有 `exit()`。结论：`exit()` 与 `quit()` 都是交互式提示符的退出别名，等价；数据库的 `quit` 是 SQL 客户端命令，与 Python 无关。其他退出方式还有 `Ctrl+Z`（Win）、`Ctrl+D`（Linux/Mac）、`sys.exit()`、`os._exit()`。
