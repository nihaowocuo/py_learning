## 第二轮深度检测（运行时边界用例）
- 发现真实崩溃 bug：`message` 为非字符串（数字/对象/列表）时，`(payload.get("message") or "").strip()` 对 int 调 `.strip()` 抛 AttributeError，且不在 try/except 内 → 连接被掐断（RemoteDisconnected）。
  - 修复：`str(payload.get("message") or "").strip()` 强制转字符串；并把 `ask()` 调用包进 try/except 兜底，保证永远返回 JSON。
- 端口占用时 `serve_forever` 抛丑陋 traceback → `run_web` 加 OSError 捕获 + 友好提示。
- 无输入长度上限 → 加 8000 字上限，避免大请求拖垮模型。
- 运行时验证：畸形JSON/空消息/缺字段 → 400；并发3请求 → 200；reset 后干净单轮问答 → 完美回复。
- 非代码问题：Qwen2.5-7B 偶发输出角色词泄漏/质量波动，属模型本身表现，reset 后正常。
